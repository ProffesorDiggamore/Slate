Privacy

Last updated October 18, 2026

The short version: Cairn has no server, no accounts and no analytics. Your notes are stored in your browser on your own device and, if you turn on sync, in a GitHub repository that you own. Whoever runs this website can't see your notes, your calendar or your passwords — the site only sends the app's code to your browser.

What's kept on your device

  • Your notes, trash and settings, in your browser's storage for this site.
  • Your GitHub access token, if you turn on sync.
  • A Google access token, if you connect Google Calendar. It expires on its own within an hour.

Each browser keeps its own copy. Someone else using Cairn on their own device has a completely separate, private copy.

Where your data goes

  • GitHub (api.github.com) — only if you turn on sync, only the repository you choose, using the token you paste in.
  • Google Calendar (www.googleapis.com) — only if you connect it. See below.
  • Nowhere else. The site tells your browser to block every other destination, so this isn't just a promise.

Links and images you add to your own notes load from wherever they point, like in any editor. The website host (Netlify) keeps the ordinary request logs every web host keeps, such as IP addresses; Cairn adds no tracking of its own.

Google Calendar

If you choose to connect Google Calendar, Cairn asks Google for permission to:

  • see the list of your calendars, so you can choose which ones to show;
  • see your events, so they appear in Cairn's calendar next to your daily notes;
  • add, change and delete events, but only when you tell it to.

Your calendar data goes straight from Google to your browser. It is never sent to, or stored on, any server run by Cairn, never shared or sold, never used for advertising, never used to train AI models, and never read by people. Events are kept in memory only while the app is open.

Cairn's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing your data

  • From a device: Settings → Data → Reset this device.
  • Google: Settings → Calendar & time → Disconnect, which also cancels Cairn's access. You can check at myaccount.google.com/permissions.
  • GitHub: delete the token at github.com/settings/personal-access-tokens. Your notes repo is yours to keep or delete.

Open source

Cairn's code is public at github.com/ProffesorDiggamore/Cairn, so anyone can check what it does, or host their own copy. Questions go in that repo's Issues.
